# CASCADE Methodology

## Overview
CASCADE is an AI-powered cyber-risk prediction and prioritisation system for critical infrastructure.
It models critical OT/ICS operational environments alongside IT enterprise networks using Purdue model zone stratification.

## Methodology Pillars
1. **Attack Graph Modeling**: Network reachability, conditional exploit probabilities using real EPSS and CISA KEV scores, and ML anomaly score boosts.
2. **Consequence Cascading (CCE)**: Physical dependency modeling based on Idaho National Laboratory's Consequence-driven Cyber-informed Engineering.
3. **Risk Quantification**: Risk = Likelihood x Consequence (0-100 scale).
4. **OT-Realistic Remediation Planning**: Choke-point identification and budget-constrained remediation action selection.
5. **Regulatory Alignment**: Indian Computer Emergency Response Team (CERT-In) guidelines mapping for Smart Cities and Critical Information Infrastructure (CII).
